# Shoaib Khan - Portfolio Website

A modern, premium personal portfolio website for **Shoaib Khan** — Content Creator, Video Editor, and Entrepreneur from Hyderabad.

## 🚀 Tech Stack

- **React 18.3.1** with TypeScript
- **Vite 5.4.2** as bundler
- **Tailwind CSS 3.4.1** for styling
- **Bootstrap 5.3.2** + React Bootstrap 2.10.1
- **Sass** for advanced custom styling
- **Lucide React** for icons
- **React Router DOM 7.6.2** for navigation
- **Lenis 1.3.8** for smooth scrolling
- **Framer Motion** for animations
- **React Helmet Async** for SEO

## 🎨 Design Features

- **Colors**: Black background (#000000), Golden Yellow primary (#FFBD59), White text (#FFFFFF)
- **Typography**: 
  - Clash Display (headings/hero)
  - Work Sans (body text)
  - Raleway (accents/subheadings)
- **Glass/blur effects** with subtle gradients
- **Smooth animations** and cinematic aesthetic
- **Responsive design** across all devices
- **SEO optimized** with structured data and Open Graph tags

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
